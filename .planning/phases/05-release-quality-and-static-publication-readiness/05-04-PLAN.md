<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CSS -> printed artifact | Styles determine what research content is visible or hidden in printed/citation use. |
| Built HTML -> print validator | Generated pages are parsed as static release evidence. |
| Validator CLI -> release orchestrator | Print readiness diagnostics become publication-blocking signals. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-04-01 | Information Disclosure | print URL expansion | accept | Expanded URLs are local/source links already visible in page anchors and source trails; no secrets are introduced. |
| T-05-04-02 | Tampering | print CSS hiding provenance | mitigate | Validator rejects broad print selectors like `aside { display: none }` and requires `.formal-source-trail` preservation. |
| T-05-04-03 | Repudiation | print validator failures | mitigate | Emit entryId, field, path, reason, and nextStep for missing CSS signals or page structures. |
| T-05-04-04 | Denial of Service | print validation | accept | Static CSS and representative HTML text checks are bounded to known files; no browser or PDF rendering process is added. |
| T-05-04-SC | Tampering | npm installs | mitigate | No new packages; browser/PDF snapshot dependencies are explicitly excluded by D-16 unless separately approved. |
</threat_model>
