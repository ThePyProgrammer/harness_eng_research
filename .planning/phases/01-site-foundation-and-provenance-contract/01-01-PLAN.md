<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository root -> site build | Site tooling reads from repo-owned files but must not write outside `site/`. |
| Markdown/MDX content -> static HTML | Authored docs and math are transformed to HTML at build time. |
| package manager -> local workspace | Bun installs dependencies only for `site/`, avoiding root package mutation. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | T | `site/package.json` | mitigate | Keep all package scripts under `site/` per D-01; acceptance checks assert no root `package.json`. |
| T-01-02 | I | `site/astro.config.mjs` | mitigate | Use static output and no SSR adapter so no server runtime exposes filesystem paths. |
| T-01-03 | D | `site/src/content/docs/*.mdx` | accept | Phase 1 docs are static authored files with no untrusted user input or accounts. |
| T-01-04 | T | math rendering pipeline | mitigate | Use `remark-math` + `rehype-katex` at build time; do not add CDN/runtime auto-render scripts. |
</threat_model>
