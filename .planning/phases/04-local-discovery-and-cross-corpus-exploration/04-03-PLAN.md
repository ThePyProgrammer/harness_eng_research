## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Pagefind static bundle -> browser UI | Client query strings and search result payloads are loaded and rendered in the browser. |
| Generated search records -> validation/build | Search metadata controls what readers can discover and must not drift silently. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-07 | Tampering | `SearchPanel.astro` result rendering | mitigate | Render only safe plain excerpts/snippets; do not inject raw Pagefind `content` as HTML. |
| T-04-08 | Repudiation | Search quality fixtures | mitigate | QUAL-03 fixtures assert specific expected hrefs/anchors and fail with diagnostics when drift occurs. |
| T-04-09 | Information Disclosure | Search index content | accept | Site indexes public static research pages only; no accounts, sessions, or private data exist. |
| T-04-10 | Denial of Service | Browser search UI | mitigate | Limit displayed loaded results per query and use Pagefind static API rather than custom heavy search logic. |
| T-04-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs in this plan; Pagefind/Vitest already exist. If executor changes dependencies, stop for package legitimacy review because vitest is slopcheck SUS but accepted as existing. |
</threat_model>
