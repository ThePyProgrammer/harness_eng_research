<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Relation/path metadata -> graph artifacts | Validated metadata is projected into public graph JSON and pages. |
| Static graph page -> reader navigation | Readers follow graph node links to corpus, formal, concept, citation, and path targets. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-11 | Tampering | Graph node/edge projection | mitigate | `validateDiscovery()` checks node IDs, relation target/type IDs, labels, hrefs, and renderability before artifacts are trusted. |
| T-04-12 | Denial of Service | Global graph overview | mitigate | Keep global graph high-level and static; avoid every-object hairball and avoid heavyweight client graph engines. |
| T-04-13 | Spoofing | Clickable graph node labels | mitigate | Node labels come from existing corpus/formal/concept/citation/path registries or validated graph records, not arbitrary unlabeled IDs. |
| T-04-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs in this plan; if executor attempts one, stop and require package legitimacy review. |
</threat_model>
