## A book/wiki for source-grounded harness research

The Harness Architecture Book Wiki is a reading interface for the corpus, not a replacement for it. Canonical content comes from `science/paper/` and `pillars/*/paper/`; the website explains, cross-links, and routes readers back to those source files instead of becoming an untraceable fork.

The homepage begins as a map because researchers need both a linear book spine and an associative overview. Start at the umbrella framework to see the shared formal architecture, then follow the twelve pillar source-detail pages in conceptual-arc order: abstraction, information, reliability, coordination, temporal dynamics, economics, model routing, human interaction, quality, security, governance, and accretion.

Phase 2 pages are deliberately source-detail pages. They expose summaries, canonical `.tex` sources, PDFs, bibliographies, provenance status, and previous/next navigation so later curated chapters can expand the math without losing the trail back to the executable research corpus.
